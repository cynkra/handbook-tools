Convert the handbook of the repository the user names, a sibling checkout of this one, to point here
([`handbook/adoption/`](/handbook/adoption/README.md)).

Use the Skill tool with `skill: handbook-adopt`, passing the user's argument as `args`: the path of the repository to convert.
Read its old pages before installing, and never commit or push in it unless asked.
