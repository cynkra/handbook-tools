# `meta/`

The documentation system itself:
how this tree is built and grows, how the prose this repository writes is written, where its evidence and its vocabulary are kept,
and what this repository decides for itself where the shared rules leave a choice open.

**A rule stated here binds every page above it.**
Shape and prose are conventions rather than preferences: a page that departs from them is corrected in review.
A preference nobody has enforced is not yet a rule, and does not belong on these pages.

**The shared pages have one home, and the local page carries the difference.**
Every page here but the glossary and the local one is shared: this repository is its home,
and every handbook built on it points here rather than carrying a copy,
so that all of them read one text and a rule improved once is improved everywhere.
What a repository chooses differently, or in addition, is stated on its local page and nowhere else.
