# `plan/`: designs, decisions, and history

*Handbook: [`meta/local/`](/handbook/meta/local/README.md) says intent lives here, and
[`meta/handbook/`](/handbook/meta/handbook/README.md) says why it stays out of the tree.*

This directory holds documents that are not part of the description of how things work today:
plans for work that is not finished, and the record of plans that came true or were overtaken.
This file names the contents, so nothing under `plan/` is an orphan.
What is current is the [handbook](/handbook/README.md)'s; where a plan and a leaf disagree, the leaf is right.
